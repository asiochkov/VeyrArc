## 1. Карта экранов и состояний

Общее для всех экранов приложения (кроме Auth и Pro):
- **Desktop**: рельса 104px (кнопка «+» 64×64 r19 `#6FA0D6`, 5 пунктов 68×48 r16), активный пункт раскрывается 48→66px по высоте с подписью (SPRING `cubic-bezier(.34,1.56,.64,1)`, .38s, задержка старта 500мс, подпись .22s с задержкой .13s, фон `linear-gradient(180deg,#f0b565,#E8A54B)`).
- **Mobile**: нижняя панель, активный пункт раскрывается 48→128px по ширине, фон `#E8A54B`, те же тайминги.
- Пункты навигации: Сегодня (home) · Привычки (checklist) · Календарь (cal) · Цели (target) · Профиль (person). Настройки и Pro — вне навигации.

### 1.2 Today (`VeyrArc Today.dc.html`)
Desktop — сетка 3 колонки, areas: `pro planner today / mood pomo pomo / streak pomo pomo / analytics focus best`. Mobile — колонка: хедер → неделя → [Аналитика | Pro] → Сегодня → Настроение → Pomodoro → Планер → [Стрик | Личный рекорд].

- Хедер: «VEYRARC», «День 14» + «из 90», шестерёнка → Настройки, аватар «AP».
- Эта неделя: 7 кругов, состояния `done` / `freeze` (штриховка + снежинка) / `today` (золотая обводка `#E8B75E`) / `empty`; «заморозка · 0/1». Desktop 64px, mobile 28px.

У каждой строки: иконка, название, «категория · подпись», 7 точек недели, стрик.

## 4. Противоречия и вопросы

Разбил на три группы. **A**: без ответа не могу начать этап 1. **B**: нужно до этапов 3–4. **C**: я предлагаю решение, подтвердите или поправьте.

### A. Блокирующие

**A1. ## 5. Индекс дисциплины — предложение формулы (согласовать до реализации)

В дизайне есть только значения, пороги статусов (≥720 «Отлично», ≥650 «Стабильно», иначе «Есть куда расти») и «% от цели» = индекс / 10.

**Индекс за период = round(1000 × Σ wᵢ·sᵢ / Σ wᵢ)**, где sᵢ ∈ [0;1], а в сумму входят только компоненты, для которых есть данные (например, нет отказов — их вес уходит в остальные).

| Компонент | Вес | sᵢ |
|---|---|---|
| Привычки | 0.35 | выполненные привычко-дни / запланированные (counter и duration — частичный прогресс, до 1) |
| Стрик-дни | 0.15 | доля дней периода, засчитанных в стрик (все обязательные выполнены или день заморожен) |
| Отказы | 0.15 | доля «чистых» дней по всем активным отказам (день со срывом = 0) |
| Цели | 0.15 | среднее по дням целей: выполнено 1, частично 0.5, пропущено 0 |
| Планер | 0.10 | выполненные задачи / задачи с датой ≤ сегодня |
| Фокус | 0.05 | среднее по дням min(минуты фокуса / 50, 1) |
| Настроение-трекинг | 0.05 | доля дней с отмеченным настроением |

- Дельта: индекс текущего периода минус индекс предыдущего периода такой же длины.
- История индекса: значение на конец каждой недели по скользящему окну 30 дней.
- Считается в SQL-функции по дням в часовом поясе пользователя.
