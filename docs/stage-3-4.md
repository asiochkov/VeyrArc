# VeyrArc — этапы 3–4: вход, база и все разделы на настоящих данных

Дата: 29.09.2026. Ветка `veyrarc-app`.

## Что работает

- **Вход.**
  - Гость с первого экрана.
  - Онбординг сохраняется.
  - Регистрация по email с 6-значным кодом; гость при этом остаётся тем же пользователем со всеми данными.
  - Вход по паролю, сброс пароля кодом.
  - Google (включится, когда будут ключи).
  - Выход и удаление аккаунта в 2 шага.
- **Сегодня:**
  - привычки дня: да/нет, счётчик, таймер;
  - серия и рекорд, неделя, заморозки;
  - настроение;
  - Pomodoro с записью сессий;
  - планер дня;
  - день арки.
- **Трекер.**
  - Привычки: создание со всеми полями, отметка, удаление, история за 12 недель, процент выполнения, лучший стрик.
  - Отказы: создание, срывы, рекорд, выбор цели.
- **Календарь.** Текущая неделя и месяц по реальным датам. Создание задач, перетаскивание, время, заметки. Сводка по категориям, прогресс на mobile.
- **Цели.** Создание, переименование, завершение с Recap, удаление. Отметка заданий, дневник, настроение, серия, месяц. Лимит Free — 3 цели.
- **Профиль.** Индекс дисциплины за неделю, месяц, год и арку, с историей. Карточки привычек, отказов, фокуса, целей и планера, активность за 12 недель, достижения, сравнение арок. Для Free — Pro-замки.
- **Настройки.**
  - Имя и email.
  - Язык сохраняется в профиль.
  - Единицы воды, 4 переключателя уведомлений.
  - Pro-карточка: для Free — приглашение в Pro.
  - Архив арок, «Начать новую Arc».
  - Экспорт всех данных в JSON.
- Без ключей Supabase (и в превью) приложение, как раньше, показывает данные из дизайна.

## Как проверено

Локально поднят тот же стек, что у Supabase: Postgres 16, сервер входа GoTrue 2.180, PostgREST 12 и почтовый ящик-ловушка для писем с кодом. На нём гоняются 5 сквозных тестов в Chromium (`app/tools/e2e-*.mjs`). Все проходят, ошибок на страницах нет:

| Тест | Что проверяет |
|---|---|
| `e2e-auth` | гость → онбординг → регистрация с кодом (неверный код отклоняется) → выход → вход (неверный пароль отклоняется) → сброс пароля кодом → вход с новым паролем |
| `e2e-today` | отметка, счётчик и настроение сохраняются после перезагрузки, серия считается |
| `e2e-tracker` | новая привычка и её отметка, новый отказ и срыв — всё на месте после перезагрузки |
| `e2e-planner` | задача в календаре и заметка сохраняются и видны на «Сегодня»; цель и дневник сохраняются |
| `e2e-screens` | все экраны на desktop и mobile, настройки сохраняются |

Экраны без данных (превью) по-прежнему совпадают с дизайном.

## Что решил сам — проверьте

1. **Индекс дисциплины** — формула, предложенная в `stage-0.md` §5. Считается от 0 до 1000 из 7 частей с весами:

   | Часть | Вес |
   |---|---|
   | привычки | 35% |
   | дни с сохранённой серией | 15% |
   | отказы без срывов | 15% |
   | цели | 15% |
   | планер | 10% |
   | фокус | 5% |
   | отметка настроения | 5% |

   Части без данных не учитываются. Скажите, если формулу нужно поменять.
2. **Когда день засчитывается в серию.** Выполнены все привычки с пометкой «в стрике». Если таких нет — хотя бы одна привычка. Заморозка тоже сохраняет серию.
3. **Онбординг.** Каждый выбранный пункт становится привычкой со своей иконкой. «Чтение 20 мин», «Прогулка 30 мин» и «Глубокая работа 90 мин» — привычки на время. «Вода» — счётчик на 8 стаканов. Пункты «Отказ от вредного» становятся отказами.
4. **Задание, добавленное в цель,** становится постоянным ежедневным заданием этой цели (B11).
5. **Pomodoro.** Фокус 25 мин, короткий перерыв 5, длинный 15; после 4 сессий — длинный перерыв. Кнопка «tune» пока ничего не делает (B1). Категорию сессии (Тело/Разум) выбрать негде, поэтому эти цифры пока 0.
6. **Корреляции в Профиле** — пока текст «паттерны появятся через 2 недели». Настоящий расчёт нужно делать на накопленных данных.
7. **Рекомендации в Профиле:** 3 общие карточки из дизайна. Карточку про цель «Путешествие» из тестовых данных убрал.
8. **Новые тексты, которых нет в дизайне:** «Этот email уже зарегистрирован», «Не получилось…», «Днём», текст про корреляции.

## Осталось

- **Запуск на настоящем Supabase** — ждёт ключ с полными правами. Одна команда `node app/tools/supabase-setup.mjs`:
  - применит миграции;
  - включит вход по коду и гостей;
  - поставит лимит повторной отправки кода 45 с;
  - подключит письма через Resend;
  - переключит сайт на Render в рабочий режим.
- **Дальше:**
  - DNS для писем и домена;
  - напоминания и уведомления;
  - PWA (установка на телефон);
  - оплата Pro.
