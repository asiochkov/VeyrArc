## Модуль 2 — голосовой ассистент (0 ₽)
- Кнопка «+»: нажатие — «Добавить», удержание — говорить; в окне «Добавить» сверху большой микрофон.
- Распознавание: Web Speech API браузера (бесплатно). Модели Whisper/WebLLM на телефоне не берём — сотни МБ загрузки.
- Команды (regex-роутер): «настроение 4», «сделал/выполнил <привычка>», «задача/напомни <текст> [завтра] [в 15:00]», «фокус 25».
- Действия только через существующие функции приложения (logMood, logHabit, saveEvent, pomo) — не прямой доступ к базе.
- Озвучка ответа (speechSynthesis) + текстовая плашка; состояния idle → слушаю → обрабатываю → отвечаю / ошибка.
- Ограничение: на iPhone в приложении с экрана «Домой» распознавание речи может быть недоступно — тогда показываем подсказку.

## Модуль 3 — интерфейс
- Welcome: оставляем текущий онбординг (одноразовый), без второго экрана.
- Навигация: нижняя панель на телефоне / сайдбар на компьютере — уже есть.
- Убрать: кнопку поиска сверху на телефоне, раздел «Горячие клавиши» в настройках.
- Планер: новая задача берёт выбранную в планере дату, а не «сегодня».
- Карточки целей: длинный текст переносится, не вылезает.

## Модуль 4 — Brain и QA
- Карточка «Режим восстановления»: при низком настроении/пропусках предлагает перенести невыполненные задачи на завтра; применяется только по кнопке «Применить».
- QA-чеклист из ТЗ + наши e2e на клоне перед выпуском.
