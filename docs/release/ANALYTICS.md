# Техническая аналитика использования

Приложение не пишет события в `app_events` и не зависит от наличия этой таблицы. Опциональная Яндекс Метрика включается только через `VITE_METRIKA_ID`; запись сеансов выключена, тексты привычек и дневника не отправляются. Для локальных тестов и staging оставлять ID пустым. Это не влияет на пользовательский экран «Аналитика», который строится по данным привычек, целей и фокуса.
