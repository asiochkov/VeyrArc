# Как выпускаем обновления

- Сайт обновляется сам из ветки `veyrarc-app` (Render, autoDeploy) — туда **не пушим**, пока не выпуск.
- Вся работа — в ветке `next`. Каждое изменение сразу дописываем в `CHANGELOG.md` → «Готовится».
- Серверная часть (база Supabase, функция уведомлений) общая с рабочим сайтом: миграции и
  функцию применяем только в день выпуска (или делаем совместимыми со старой версией).
- Выпуск: тесты → `git checkout veyrarc-app && git merge next && git push` → Render выкатывает →
  метка `beta-1.1` (и т. д.) → текст «Что нового» из CHANGELOG.
- Срочный фикс без ожидания: коммит в `veyrarc-app`, затем `git merge veyrarc-app` в `next`.
