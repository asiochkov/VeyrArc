# Как выпускаем обновления

- **Рабочее приложение** — ветка `veyrarc-app` → https://veyrarc.onrender.com. Автообновление **выключено**:
  ничего не уходит на сайт, пока не нажат ручной деплой.
- **Клон для проверки** — ветка `develop` → https://veyrarc-staging.onrender.com (метка «ТЕСТ»,
  ставится на телефон отдельной иконкой «VeyrArc ТЕСТ»). Обновляется сам после каждого коммита в `develop`.
- **Базы раздельные:** клон работает со своей базой Supabase (`veyrarc-staging`), рабочие данные не трогает.
- Изменения базы — только файлами миграций в `supabase/migrations`.
- Каждое изменение сразу дописываем в `CHANGELOG.md` → «Готовится».
- **Выпуск** (только после «ок» владельца): тесты и QA-чеклист на клоне → `develop` сливается в `veyrarc-app` →
  ручной деплой на Render → миграции на рабочую базу → ветка `release/<версия>` → текст «Что нового».
- Ветка `release/beta-1.0` — код, который был на сайте 1 октября (точка отката).
