# QA-чеклист обновления 1.1 (ТЗ, раздел 4.2)

Проверено на локальной копии (та же сборка, что уходит в клон) 7 октября 2026.
Автотесты: `app/tools/e2e-*.mjs`, юнит-тесты: `app/tools/unit`.

## 1. Безопасность и изоляция данных
- [x] **Секретного ключа Supabase (service role) нет в сборке.** В `dist` только один ключ — публичный (`role: anon`).
- [x] **Чужие данные недоступны (RLS).** Пользователь B не видит настроение пользователя A (пустой ответ), не может изменить или удалить чужую привычку, а запись от имени A отклоняется с кодом `42501`.
- [x] **Одна почта — один профиль.** Повторная регистрация с той же почтой возвращает того же пользователя: в базе 1 запись в `auth.users` и 1 в `profiles`.

## 2. Интерфейс
- [x] **Приветствие показывается один раз.** Это текущий онбординг; при повторном входе сразу открывается «Сегодня» (`e2e-auth`).
- [x] **Нижняя панель на телефоне (< 1024px)** плавает внизу, отступы с учётом выреза, кнопки нажимаются (`e2e-screens`, `e2e-voice`). Известное замечание `e2e-mobile-audit` — наложение «Заморозка серии» на панель при прокрутке — было и до 1.1.
- [x] **Боковое меню на компьютере (≥ 1024px)** (`e2e-screens`).
- [x] **Убраны** поиск сверху на телефоне и раздел «Горячие клавиши» в настройках.

## 3. Голосовой ассистент
- [x] **Нажатие на знак ассистента сразу включает запись** (`e2e-voice`). В ТЗ это «центральная кнопка» меню; у нас знак стоит справа от панели.
- [x] **«Настроение …» записывает настроение за сегодня и отвечает голосом и текстом.** Шкала у нас 1–5 («настроение 4», «настроение отличное»), а не 1–10.
- [x] **Нет доступа к микрофону — состояние ошибки** (красный шар) и понятный текст: «Нет доступа к микрофону или распознаванию речи. Разрешите их в настройках браузера.»

## 4. Brain: режим восстановления (ТЗ 4.1)
- [x] Карточка появляется:
  - при низком настроении сегодня или низком среднем за 3 дня;
  - после пропуска вчера (привычки или 2+ невыполненные задачи);
  - вечером, если осталось 2+ задачи.
- [x] **Ничего не меняется до «Применить»** (`e2e-lighten`). После применения задачи переносятся на завтра, в уведомлении есть «Вернуть». «Не сейчас» скрывает карточку до конца дня.

## 5. Офлайн (модуль 1)
- [x] Отметка без сети отправляется, когда связь вернётся (`e2e-offline`).
- [x] Отметка без сети переживает закрытие приложения без сети. Она отправляется при следующем запуске, после входа в тот же аккаунт (`e2e-offline`).
