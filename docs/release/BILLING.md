# Оплата удалена

VeyrArc полностью бесплатен. Тарифы, платежный frontend, Edge Function billing, реферальная программа и их тестовые серверы удалены. Не разворачивать платёжную инфраструктуру.

Старые SQL-миграции остаются историей схемы, чтобы не нарушать существующие установки. Новая миграция `20261030075328_free_app_reliability.sql` отключает коммерческие функции и ограничения, сохраняя существующие записи. Порядок подготовки базы и выпуска описан в [PROCESS.md](PROCESS.md).
