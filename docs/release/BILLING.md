# Оплата подписки через ЮKassa

## Как это работает

1. На экране Pro человек выбирает тариф (месяц или год) и отмечает согласие на автопродление.
2. Приложение просит сервер создать платёж. Серверная функция `billing` создаёт его в ЮKassa и
   включает в него чек по 54-ФЗ.
3. Человек вводит карту на странице ЮKassa (карта, СБП или SberPay) и возвращается на `/pro?paid=1`.
   Сервер сам проверяет платёж в ЮKassa и включает Pro. Параллельно то же самое делает
   уведомление от ЮKassa.
4. Если оплата прошла, карта сохраняется на сервере (её ID в `private.billing_methods`;
   приложение его не видит).
5. Раз в день сервер списывает оплату за следующий период с подписок, которые
   заканчиваются в ближайшие сутки:
   - если банк отказал, сервер пробует ещё 3 дня;
   - если и это не помогло, Pro просто заканчивается.
6. В «Настройки → План» есть кнопка «Отключить автопродление»:
   - Pro остаётся до оплаченной даты;
   - карта отвязывается.
7. Возврат делается в кабинете ЮKassa. ЮKassa присылает уведомление, и Pro закрывается.
8. Пробный период на 7 дней без карты остаётся (по одному на аккаунт). Если оплатить во
   время пробного периода, оплаченный срок прибавится к его концу.

Гостевой аккаунт платить не может: приложение попросит сначала сохранить аккаунт с почтой,
потому что чек приходит на почту, а покупка привязывается к аккаунту.

## Что сделать в кабинетах (делаете вы, ключи никому не пересылайте)

### 1. ЮKassa

- Зарегистрируйте магазин на yookassa.ru (ИП или самозанятый) и создайте **тестовый магазин**
  (в кабинете — «Тестовый магазин»).
- Подключите **автоплатежи** (рекуррентные платежи): их нужно согласовать с менеджером ЮKassa.
  Без этого карта не сохраняется.
- Подключите **чеки** («Чеки от ЮKassa»). Если чеки не нужны, задайте `YOOKASSA_RECEIPT=0`.
- В «Интеграция → HTTP-уведомления» укажите адрес:
  `https://<project-ref>.supabase.co/functions/v1/billing?hook=yookassa`
  и отметьте события `payment.succeeded`, `payment.canceled`, `refund.succeeded`.

### 2. Supabase: сначала тестовый проект для клона, потом рабочий

Миграция: `supabase/migrations/20261015000001_billing.sql`.

Секреты функции (Project Settings → Edge Functions → Secrets):

| Секрет | Значение |
|---|---|
| `YOOKASSA_SHOP_ID` | shopId из кабинета ЮKassa |
| `YOOKASSA_SECRET_KEY` | секретный ключ (у тестового магазина начинается с `test_`) |
| `BILLING_CRON_SECRET` | любая длинная случайная строка |
| `APP_URL` | `https://veyrarc-staging.onrender.com` (для клона) или адрес рабочей версии |
| `PRICE_MONTHLY`, `PRICE_YEARLY` | цены в рублях; должны совпадать с `app/src/config.ts → pricing.ru` |

Функцию нужно развернуть без проверки токена Supabase: уведомление от ЮKassa приходит без
токена, а пользовательские запросы функция проверяет сама.

```
supabase functions deploy billing --no-verify-jwt
```

Ежедневное автопродление (SQL Editor, нужны расширения `pg_cron` и `pg_net`):

```sql
select cron.schedule('billing-renew', '17 6 * * *', $$
  select net.http_post(
    url := 'https://<project-ref>.supabase.co/functions/v1/billing',
    headers := jsonb_build_object('content-type', 'application/json', 'x-cron-secret', '<BILLING_CRON_SECRET>'),
    body := '{"action":"renew"}'::jsonb);
$$);
```

### 3. Включить платную версию

- В базе: `update private.flags set beta = false;` (иначе Pro открыт всем).
- На Render у нужного сервиса задайте переменную `VITE_BETA=0` и пересоберите.

Делайте это сначала на клоне с отдельным тестовым проектом Supabase. Сейчас клон работает на
рабочей базе, поэтому выключать бету на нём нельзя.

## Проверка

Тестовые карты ЮKassa (тестовый магазин):
- `5555 5555 5555 4477` — успешная оплата;
- `5555 5555 5555 4592` — отказ.

Срок действия — любой будущий, CVC — любой.

Локально весь сценарий проверяется автотестом с заглушкой ЮKassa:

```
bash app/tools/local-backend/up.sh && bash app/tools/local-backend/functions.sh
cd app && VITE_BETA=0 npm run build && node tools/e2e-billing.mjs
```

Автотест проходит по шагам:
1. Защита сервера.
2. Оплата за год с согласием.
3. Pro включён, карта сохранена.
4. Повторное уведомление ничего не меняет, поддельное отклоняется.
5. Автопродление списывает один раз.
6. Отказ банка обрабатывается.
7. Отключение продления в настройках.
8. Возврат закрывает Pro.
