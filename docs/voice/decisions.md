# Принятые решения (ТЗ, раздел 3 и 4)

Одна строка на решение: дата · решение · причина.

- 2026-10-28 · Порог golden-набора включается как обязательный в WP3.5 (`tools/voice/golden/config.json`, `enforce`). До этого `npm run test:voice` показывает цифры и падает только на юнит-тестах: старый парсер заведомо ниже порогов (см. baseline.md), а требовать зелёного до появления нового парсера значило бы блокировать все пакеты.
- 2026-10-28 · Эталонные фразы приложения E взяты из PDF; в нём длинные строки обрезаны по ширине страницы, поэтому ожидания (slots) переписаны по таксономии 6.6 заново, а смысл фраз сохранён.
- 2026-10-28 · Слова «арка» и «90 дней» не используются в текстах ассистента и релиз-нотах этой работы: говорим «сезон» (решение владельца из ТЗ).
- 2026-10-28 · `task.add`: обязателен только `title`. День без указания — сегодня. Время спрашивается (ask-slot «На какое время?») только если в фразе есть день и название похоже на событие со временем (встреча, созвон, врач, стоматолог, ужин, обед, интервью): иначе «купить хлеб» превращалось бы в допрос.
