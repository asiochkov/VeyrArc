# Проба локальных движков (ТЗ 6.19)

Дата: 2026-10-28. Среда проверки: сервер разработки без телефона; доступ в сеть через прокси (GitHub raw и npm открыты; страницы моделей Vosk и Hugging Face закрыты).

## Распознавание речи на устройстве

| Кандидат | Что подтверждено | Что не подтверждено | Итог |
|---|---|---|---|
| (a) расширенный Web Speech (подсказки `phrases`, `processLocally`) | Это возможности самого браузера; код (WP2.2) включает их только по обнаружению и по согласию человека | Работа на iPhone (Safari не поддерживает `processLocally` и `phrases`; проверяется в Voice Lab) | **принят как основной путь**, всё через `try/catch` |
| (b) vosk-browser (WASM в Web Worker) | npm-пакет `vosk-browser` 0.0.8, лицензия Apache-2.0, работает в Worker; в README заявлены 13 языков | Существование и точная лицензия русской «small»-модели, её размер: страница моделей `alphacephei.com/vosk/models` из этой среды недоступна | **не принят: русскую модель и её лицензию нельзя подтвердить отсюда** (правило 6.19.2) |
| (c) другие движки с русской моделью | не искались: условие (b) не выполнено, пороги всё равно может измерить только владелец | — | не принят |

Что сделано вместо: `SttEngine` уже имеет идентификатор `'local'`, флаг `flags.localAsr` и настройка `prefs.localAsr` существуют и выключены. Когда русская модель будет подтверждена, достаточно добавить `stt/local.ts` и зарегистрировать его в `stt/router.ts`. Измерения (порог ≥ 90% на 80 фразах, ≤ 100 МБ, старт ≤ 4 с на iPhone 16 Pro Max) делает владелец через Voice Lab.

## Озвучка на устройстве (Piper)

- Подтверждено по `VOICES.md` репозитория Piper (GitHub): русские голоса существуют — `ru_RU-denis`, `ru_RU-dmitri`, `ru_RU-irina`, `ru_RU-ruslan` (medium).
- Не подтверждено: лицензия каждого голоса (карточки моделей на Hugging Face из этой среды недоступны), размер на устройстве и скорость первого звука в браузере через onnxruntime-web.
- Итог: **не принят: лицензии русских голосов подтвердить нельзя**. `flags.localTts` существует и выключен; `tts/piper.ts` не создаётся.
