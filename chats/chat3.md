Файл: `Winterwork Training.dc.html`. Ниже — конкретные правки, без обоснований.

## Новая структура раздела

Добавить два новых полноэкранных экрана: **«Активная тренировка»** и **«Итог тренировки»**.

Опционально третий новый экран: **«Онбординг подбора программы»** (квиз из 3–4 шагов).

## Экран «Сегодня» (переименовать текущий «Обзор»)

1. Наверху экрана, первым блоком (без скролла) — hero-карточка **«Тренировка на сегодня»**: название дня из активной программы («Push · День 3»), 3–4 иконки упражнений этого дня, длительность («~48 мин · 6 упражнений»), крупная кнопка **«Начать тренировку»** → ведёт на экран «Активная тренировка».
2. Если по программе сегодня день отдыха — та же зона показывает **«Сегодня отдых»** с иконкой восстановления и короткой фразой поддержки, а не пустоту.
3. Карточку CONSISTENCY (стрик) переместить ниже hero-блока.
4. Кнопку **«Отметить тренировку»** удалить. Отметка выполнения проставляется автоматически после прохождения «Активной тренировки». Отдельно добавить маленькую ссылку **«Записать вручную»** (для тренировки без приложения) с полями: длительность, тип.
5. Карточку LAST WORKOUT: убрать выдуманный «+3% объём», подставлять реальные данные последней сессии (подходы/веса из лога) либо не показывать метрику вовсе, пока лога нет.
6. Карточку PROGRESS (Strength/Volume): на переходный период заменить на список последних 3 тренировок (дата · сплит · длительность) вместо процентных полосок без источника данных.
7. Перевести на русский: «Strength» → «Сила», «Volume» → «Объём», «workouts всего» оставить как есть на русском, «time in gym» → «время в зале», «avg. session» → «средняя сессия».
8. Карточку ACTIVE PROGRAM сделать кликабельной целиком (не только текст-ссылка), добавить строку «Дальше: День 4 · Legs».
9. Пустое состояние «Программа не выбрана»: заменить на карточку с рекомендованной программой (по данным онбординга, если он есть) и кнопкой «Начать» в один тап, без перехода в библиотеку.
10. Гистограмму TRAINING FREQUENCY на мобильном показывать по умолчанию в режиме 4W, переключатель 12W спрятать под «Показать больше».

## Экран «Активная тренировка» (новый)

1. Полноэкранный режим, без боковой рельсы и нижней навигации. Кнопка выхода/паузы вверху слева.
2. На экран — одно упражнение: название, иллюстрация/схема движения, целевые подходы × повторы.
3. Список подходов текущего упражнения, по тапу на подход — сразу поле ввода факта (вес, повторы), без отдельной формы.
4. Таймер отдыха между подходами — автозапуск после отметки подхода выполненным. Кнопки +15 сек / −15 сек / «Пропустить отдых».
5. Прогресс тренировки целиком: «Упражнение 3 из 6» + полоса прогресса.
6. Если есть история по движению — подсказка прогрессии: «Прошлый раз: 70 кг × 8. Попробуй 72.5 кг».
7. Иконка «⇄» рядом с названием упражнения — замена на альтернативное движение.
8. Кнопка «Завершить тренировку» доступна на любом шаге → ведёт на «Итог тренировки» с честным подсчётом (выполнено X из Y).

## Экран «Итог тренировки» (новый)

1. Сводка: длительность, число подходов, общий объём (кг × повторы).
2. Если есть новый личный рекорд по любому движению — отдельный блок «Новый личный рекорд 🏆», золотой акцент (`#E8B75E`) — второй по счёту случай золотого цвета в системе после Pro-плашки.
3. Обновление стрика — показать здесь с анимацией кольца/пламени.
4. Блок «Как ощущения?» — 5 эмодзи, переиспользовать компонент «Настроение» с экрана «День».
5. Кнопка «Готово» → возврат на «Сегодня».

## Экран «Библиотека»

1. Каждой карточке программы — цветной верхний блок/обложка в цвете сплита по уже существующей карте `PLACE_COLOR` (Зал — `#6FA0D6`, Дома — `#5FBF9B`, Улица — `#E8B75E`, Турники — `#9B87D6`), не только мелкий текстовый чип.
2. На карточке добавить оценку длительности разовой сессии («~45 мин»).
3. Добавить фильтр по длительности сессии (например: до 30 мин / 30–60 / 60+).
4. При выборе новой программы, если уже есть активная с прогрессом — показывать подтверждение: «Текущий прогресс по [название] (день X) будет приостановлен. Продолжить?».

## Экран «Программа» (детальный)

1. Строки расписания (`Пн — Full Body` и т.д.) сделать кликабельными — по тапу открывается список упражнений этого дня (названия + число подходов).
2. Добавить кнопку **«Начать день X»** для текущего дня программы прямо на этом экране.
3. У тегов уровня («Начальный/Средний/Продвинутый») добавить всплывающую подсказку с расшифровкой критерия уровня.

## Экран «Упражнение» (новый, фаза 2)

1. Карточка движения: техника (иллюстрация или видео), задействованные мышцы, история весов/повторов по этому упражнению, личный рекорд.
