# Winterwork — Today: точное воспроизведение (для Claude Design)

## Задача
Воссоздай экран "Today" приложения Winterwork **пиксель-в-пиксель** по двум приложенным скриншотам:
- `Reference_Mobile.png` — мобильная версия (390×844, iPhone)
- `Reference_Desktop.png` — десктоп-версия (1280×832, с боковой навигацией)

Это не референс "в общих чертах" — это финальный, утверждённый дизайн. Копируй расположение, отступы, радиусы скругления, цвета, шрифты, размеры карточек как можно точнее.

## Обязательно: обе версии, с переключением
Сделай так, чтобы я мог **просматривать и мобильную, и десктопную версию** в одном проекте — либо как два отдельных фрейма/страницы в рамках одного файла, либо с переключателем viewport (mobile/desktop). Не делай только одну версию.

## Ключевые детали дизайн-системы
- Фон: `#05070A` (почти чёрный), карточки — `rgba(13,17,22,.85)` с блюром (glassmorphism), тонкая ледяная обводка `rgba(168,203,239,.10)`
- Акцент: `#6FA0D6` / `#A8CBEF` (icy blue) — используется только для активных/выбранных состояний, не как декор
- Исключение: PRO-плашка "Winter Arc Pro" — единственное место с золотым/амбер акцентом (`#E8B75E`), специально выделена как premium-момент
- Шрифты: Manrope (интерфейс), JetBrains Mono (все цифры и метрики — таймер, проценты, стрики)
- Радиусы: крупные карточки — 18-24px, кнопки — полностью скруглённые (pill)
- Мобильная навигация — плоская панель внизу экрана (не "плавающая таблетка")
- Десктоп — боковая рельса слева с иконками, активный пункт подсвечен

## Структура экрана (сверху вниз)
1. Хедер: логотип/название + день арки ("День 14 из 90") + иконка настроек + аватар
2. "Эта неделя" — 7 кружков дней с историей выполнения
3. Два виджета в ряд: "Аналитика дня" (кольцо-прогресс + разбивка по категориям) и "Winter Arc Pro" (upsell-карточка, золотой акцент, кнопка "Открыть Pro")
4. Список привычек "Сегодня" — чекбокс, иконка категории, название, недельная история (точки), счётчик стрика
5. "Настроение" — 5 лиц (эмоции), явный выбор одним тапом
6. Pomodoro-таймер — табы (Фокус/Короткий/Длинный), крупное кольцо с цифрами, 3 кнопки управления
7. "Планер" — список пунктов на сегодня (время + название) + ссылка "Открыть планер"

На десктопе эти блоки собраны в сетку (не просто одна колонка) — смотри точное расположение на `Reference_Desktop.png`.

## Что важно не потерять
- Разные визуальные веса карточек: PRO-плашка и Планер — не однотипные "заголовок+число", у каждой свой состав контента
- Кольцо прогресса используется дважды (Аналитика дня, Pomodoro) — это осознанный повторяющийся мотив, не совпадение
- Именные иконки у категорий привычек (капля, книга, гантеля, щит), не абстрактные точки
